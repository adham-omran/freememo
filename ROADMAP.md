# FreeMemo Roadmap

Ordered by intent, not by calendar, `Now` is under construction, `Next` is queued, `Later` is direction. Nothing here is a commitment, and items move between sections as priorities change.

Shipped work is recorded in [CHANGELOG.md](CHANGELOG.md).

## Now

- [Video] Iterate on the video kind.
- [Quiz] Improve generated question wording.
- [Quiz] Improve UX

## Next

- [Assistant] Composer polish — input typography, per-message card generation, icon set.
- [Editor] Image sizing and numeric font size in the editor.
- [Editor] Right-click an image to copy or save it.
- [Import] Name new topics by date instead of "Untitled".
- [Mobile] Card-count control and done-count visible in narrow layouts.

## Later

- [Learn] Track time spent reading.
- [Import] ZIM archive import.
- [Import] RSS feed ingestion.
- [Import] Browser extension and bookmarklet capture.
- [Import] SuperMemo collection import.
- [Import] Cache images locally for imported articles.
- [Learn] Keep the session alive when opening an item from it.
- [Docs] Document how FreeMemo sanitizes imported content.
- [Editor] Poetry support.
- [Editor] Preserve relative and in-page links in imported HTML.
