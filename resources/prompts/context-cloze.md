- You receive one JSON object.
  - `context` contains surrounding text.
  - `content` contains the text for the cards.
  - `card-count` contains the required number of cards.
- Use `context` to understand `content`.
- Make cards only from `content`.
- Create cloze deletions ONLY from the content, not from the surrounding context text.
- Each cloze must contain one to three words.
- Split a long highlighted phrase into multiple short clozes in the same card.
- The context value "المادة" identifies legal content.
- For legal content, use the question form "ماذا نصت المادة س من قانون ص؟"
