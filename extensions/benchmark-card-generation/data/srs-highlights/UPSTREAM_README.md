# SRS Highlights

`srs-highlights` is a collection of reader highlights, each paired with its source context and the full set of rated memory prompts written for it. It is the highlight-level view of [`laddermedia/srs-prompts`](https://huggingface.co/datasets/laddermedia/srs-prompts): one row per highlight, with every tier-labeled prompt attached as a reference.

See the [Memory Machines appendix](https://memory-machines.com/appendix#a-the-srs-prompts-dataset) for details on the dataset, including the taxonomy, collection methodology, and schema.
